# E0025–E0027：先完成训练日程，再检验 static 均值锚点

状态：三个 Level 1 实验已规划和登记，尚未训练。当前目标是改善未来 dFC 的复原和个体差异，不进行 GRU 与 Transformer 的优劣排名，也不使用测试集挑选设置。

## 固定设置与变化

| 实验 | 基础 | 唯一实际设置 | 研究作用 |
| --- | --- | --- | --- |
| E0025 | E0018 的 GCN+GRU、MSE 差分 1＋方差 1 | 150 epoch；5 epoch warm-up＋余弦退火；不早停 | 看该架构在更完整的训练日程下能否摆脱复原与个体性缺陷。相对 E0018 **同时改变训练时长和学习率日程**，不能单独归因余弦。 |
| E0026 | E0024 的 GCN+Transformer、相同动态损失与余弦策略 | 150 epoch；不早停 | 为较长训练预算提供一个无 static 的固定参照。相对 E0024，余弦曲线随总轮数拉长，不能当作纯粹追加 50 轮。 |
| E0027 | E0026 全部设置 | 仅增加 `0.01 × L_static` | 检验未来时间均值锚定能否修正 FC 水平、带来真实被试差异，同时保留动态。 |

三个实验均沿用 LR 数据、被试划分、FC 首窗条件、GCN SC 编码、冻结的 E0003 FC 重建 decoder、seed 42 和验证集选模。初始学习率为 `3e-4`；前 5 轮线性 warm-up，余下 145 轮余弦退火至 `1e-5`。`patience: 151` 使 150 轮全部执行，但每轮仍会按验证目标更新 `best.pt`；它不是“使用最后一轮模型”。

E0027 的 `static` 为预测与真实未来 223 个 FC 窗口在时间维取平均后的逐边 Fisher-z MSE。`0.01` 是预先固定的探索权重，不是已验证最优值：E0024 验证集边 MSE 约 2.30，而差分＋方差目标约 0.015，直接沿用之前示例的 `0.1` 可能让均值项压倒动态项。运行前在训练批次上记录三个未加权损失及梯度尺度；若 `0.01` 明显失衡，应停止并另立新配置，不能在 E0027 已登记目标下悄悄改权重。静态均值约束可能只学到群体均值，不能以总误差下降代替个体性证据。

## 执行顺序

1. 审核配置与登记哈希，准备训练环境、冻结数据/划分及 A0003 checkpoint；将本轮配置、登记和现有文档改动形成干净 Git 状态。Level 1 运行会拒绝脏工作区。
2. 分别运行 E0025、E0026 至完整 150 epoch；查看每轮损失及学习率、最佳轮次、最终轮次。两个架构各自回答能否达到研究目标，不互相排名。
3. 在 E0026 作为固定参照之后运行 E0027。E0027 与 E0026 的差别仅为 static 损失，因此可以做针对锚点作用的配对诊断；不同损失定义的 `objective_loss` 数值不得直接比较。
4. 只在验证集做动态审计和个体性检查；模型达到事先确认的复原、个体性和时间动态标准后，再考虑独立 seed 与正式确认。当前已有探索性测试集接触，同一测试集不再声称完全未见过。

## 验证集诊断与判断

三个实验各自报告总体边 MSE、逐被试未来平均 FC MSE、差分 MSE、非重叠长时距的动态幅度与差分时间相关。个体性至少拆为三部分：预测平均 FC 的跨被试离散度相对真实离散度；平均 FC 的被试检索；预测序列各自去时间均值后的跨被试相似性。现有 `retrieval_top1` 主要反映静态指纹，不能充当动态个体性指标。

另在完整验证集分别交换 SC 和首窗 FC 条件，量化输出变化相对真实跨被试差异的幅度，并对去时间均值后的序列重复检查；这能区分“仅均值会随被试变”与“动态也依赖被试”。交换条件只是敏感性诊断，非因果证明。

E0027 的正向信号是：平均 FC MSE 和总体边 MSE 下降，预测的被试间差异与静态检索不再接近随机，同时差分时间相关与动态幅度未明显恶化。若只看到边 MSE 下降而预测仍几乎相同，结论应为“锚点改善水平复原，未解决个体差异”。若个体均值改善但去均值动态仍高度共享，则下一步应处理条件注入/时序机制，而不是宣布科研闭环完成。

当前评价管线尚未直接输出平均 FC MSE、完整验证集条件交换和去均值跨被试相似性的全部指标；在解释这三个实验前，应补一份只读诊断脚本或评价扩展，并固定其计算口径。此次计划不启动训练，也不生成结果。
