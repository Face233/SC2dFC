# E0038：E0036 直接残差 Transformer 的差分与方差联合损失

## 问题与对照

E0036 在验证集的长期边 MSE 为 0.184294，但预测动态振幅很低（动态标准差比约 0.00166），动态时间相关接近零。E0038 检查：保留相同 FC1-only 架构与训练协议，只改变训练损失，是否能恢复**时间上对齐的**未来变化，而不牺牲长期数值精度。

E0038 继承 E0036 配置，因此使用相同的数据与被试划分、冻结 E0003 FC encoder、冻结 E0032 模板及衰减参数、SC 编码后置零、concat 投影、四层 Transformer、4005 边直接残差头、seed 42、AdamW、warm-up cosine、150 epoch。没有重新拟合冻结工件。唯一实验变量是损失。

## 冻结损失与选模

令 `B` 为 E0032 解析基线、`r = y - B`、`r_hat` 为模型直接输出的残差。训练批次的目标预注册为

`L = MSE(r_hat, r) + 0.25 MSE(Δr_hat, Δr) + 1.0 MSE(Var_t(r_hat), Var_t(r))`。

`Δ` 为相邻未来窗一阶差分；`Var_t` 为各被试、各边在全部 223 个未来窗上的有偏时间方差。三个分量使用原始数值，不做自动归一。权重 `1/0.25/1` 沿用仓库 E0009 的既有组合，避免依据本轮验证结果调参。保留逐点 MSE 以约束绝对值；差分、方差都作用于残差，这和 E0036 的逐点目标采用相同的基线分解。静态、对比及其他目标权重为零。

完整训练 150 epoch，不早停；以验证集无重叠段 `t=17:223` 的边 MSE 选择 checkpoint。这里的选模目标与 E0036 相同，即使 E0038 的训练目标包含差分和方差。仅使用验证集评价；本轮不查看测试集。

## 评价与判读

对同 seed 的 E0036 run 做被试级配对比较，主报告长期边 MSE 的差值与被试 bootstrap 95% 区间。并列报告真实与预测的逐边时间 Pearson、去训练折群体模板后的时间 Pearson、动态残差相关、相邻窗差分相关、动态标准差比与分段 MSE。方差或标准差比上升只能说明振幅变化，不能单独证明时间轨迹预测变好；若时间相关无改善而 MSE 变差，记录为无效权衡。若时间相关改善而 MSE 变差，明确报告权衡，不以单一指标宣告成功。

E0038 是差分与方差的**联合**干预，单次对照无法将增益归因到其中一项。若联合目标显示可重复收益，后续分别登记单项消融与多个 seed。本轮固定一组权重，不针对验证集搜索。

## 本机 seed 42 验证结果（2026-09-29）

完整训练 150 epoch，按预定长期 MSE 选中第 15 轮（日志从 1 计数）的 checkpoint。验证集含相同的 158 个被试/run，配对差值均定义为 E0038−E0036。使用被试级 bootstrap 10,000 次、seed 42 计算 95% 区间。

| 验证集指标 | E0036 | E0038 | 配对差值（95% 区间） |
| --- | ---: | ---: | ---: |
| 无重叠长期边 MSE | 0.184294 | 0.184268 | −0.000026（−0.000514, 0.000442） |
| 原始逐边时间 Pearson | 0.070503 | 0.070546 | +0.000042（+0.000003, +0.000080） |
| 去群体模板时间 Pearson | 0.017518 | 0.018012 | +0.000493（−0.000044, +0.001033） |
| 动态残差时间 Pearson | 0.001957 | 0.005371 | +0.003414（+0.001090, +0.005881） |
| 相邻窗动态差分 Pearson | −0.000261 | −0.000356 | −0.000095（−0.000199, +0.000013） |
| 动态标准差比 | 0.001658 | 0.002291 | +0.000633（+0.000598, +0.000669） |

长期 MSE 的变化没有通过预定配对区间判据。动态残差时间相关有数值上可检测但绝对值很小的提升，相邻窗差分相关仍接近零且未改善；标准差比虽增加约 38%，预测动态振幅仍只有真实值的约 0.23%。因此，当前结果不支持“差分与方差联合损失已解决时间轨迹预测”这一结论。后期验证 MSE 上升，最优模型来自早期轮次。此结果仅有一个 seed，不对两项损失各自的作用作因果归因。
