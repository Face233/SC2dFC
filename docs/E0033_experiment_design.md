## E0033：首窗 FC 能否预测剩余的稳定个体成分？

**唯一主要变化：**在固定的 E0032 预测 `B` 上，加一个由首窗 FC 预测的、在全部未来时距共享的稳定残差 `hat m`。输出为 `hat y=B+hat m`；动态残差预测固定为零。不使用 SC、E0003 decoder、Transformer、差分损失或方差损失。Ridge 的平方误差直接监督真实 `m`。

**模型：**使用 E0003 已冻结的 256 维 FC encoder，把首窗 `x` 编码为 `z`；不使用 E0003 decoder，也不微调 encoder。训练折拟合的特征标准化之后，用多输出 Ridge 从 `z` 直接预测 `m` 的 4005 条边。Ridge 是 E0033 的预测头，损失为 `||m-hat m||² + lambda||W||²`。PCA 不进入本次主实验；如要比较表示方法，应在后续独立消融中保持同一个 Ridge 头和评价口径。

**正则化选择：**在训练被试内部做 5 折 subject 分组交叉验证。首轮网格 `{1,10,100,1000}` 的分数持续随 alpha 增大而下降，因此扩展为 `{1,10,100,1000,1e4,1e5,1e6,1e7,1e8,1e10}`，检查高惩罚区间是否趋于平台。每折仅在训练部分拟合编码特征的标准化与 Ridge；候选评分使用留出部分的长期平均残差目标。E0032 的基线和 E0003 encoder 均是已冻结的官方训练折工件，二者曾使用内部留出被试的数据，因此这里的内部交叉验证只负责选择惩罚强度，不当作完全独立的泛化估计。正式性能结论只使用未参与这两个工件拟合的 158 名验证被试。选定惩罚后，用完整训练折拟合标准化与 Ridge；验证集只评价一次。

**主要对照：**同一验证被试的 E0032 零残差预测 `B`。主指标为 `t=17:223` 的逐被试边 MSE 差 `MSE(E0033)-MSE(E0032)`，报告均值和被试 bootstrap 95% 区间；另报 `0:17`、`17:85`、`85:154`、`154:223` 四段。短期与长期不混成一个结论。

**辅助指标：**`hat m` 对真实 `m` 的边 MSE 和边相关、未来平均 FC 的本人检索 Top-1/Top-5/平均名次，以及预测与真实的跨被试离散度比。E0032 的静态 Top-1 已达 67.72%，因此不把 Top-1 再上升设为唯一成功门槛。E0033 的偏移在时间轴上恒定，逐边去时间均值后的预测轨迹与 E0032 完全相同；不宣称动态改善。

**建议的推进条件：**长期 MSE 的被试配对差值 95% 区间上界低于零，且稳定残差目标的 MSE 优于 `hat m=0`；同时报告实际改善百分比，讨论是否达到有意义的幅度。若只在与首窗重叠的 `0:17` 改善，不能视为长期成功。若失败，仅说明这一冻结 encoder＋线性预测头方案未检出稳定残差增益，不能排除其他表示、非线性预测头、SC 或更多历史中的信息。

## 后续实验按 E0033 结果分开安排

E0033 验证集无重叠长期 MSE 为 `0.182871`，E0032 为 `0.185801`，逐被试配对差 `-0.002930`、95% bootstrap 区间 `[-0.005163,-0.000763]`；实际降幅约 1.58%。静态本人检索 Top-1 从 E0032 的 67.72% 降至 64.56%。因 `hat m` 沿时间恒定，它不改变逐边 Pearson 时间相关。数值见 [E0033 验证报告](../outputs/E0033/runs/E0033-s42-20260928T084531Z-f04f04e/evaluation_val.json)。

| 暂定编号 | 单一问题 | 建议做法和关键对照 |
| --- | --- | --- |
| E0034 | 首窗 FC 能否预测**正确时间**的动态残差 `d`？ | 固定 E0032 基线，训练折动态残差 PCA＋Ridge 预测低维系数；输出 `B+hat d`，不带稳定偏移。以逐边时间相关、动态差分相关和长期 MSE 对照 `B`。详见 [E0034/E0035 配对设计](E0034_E0035_dynamic_residual_design.md)。 |
| E0035 | E0033 的 `m` 对动态模型是否仍有数值收益？ | 使用与 E0034 完全相同的动态头与 `B`，只叠加冻结 E0033 的 `hat m`。时间相关应保持不变，配对比较长期 MSE。 |
| E0036（待训练） | Transformer 直接残差头能否从 FC1 提取额外信息？ | 固定 E0032 的 `B`，冻结 E0003 FC encoder，SC 表示在编码后置零；Transformer 直接预测完整 4005 边残差，仅用 MSE。详见 [E0036/E0037 配对设计](E0036_E0037_direct_residual_transformer_design.md)。 |

| 后续 | 低维残差表示或动态损失是否有帮助？ | 仅在直接预测残差值已经稳定改善后，再比较专门的 residual autoencoder；差分 MSE 是下一轮独立损失消融，方差项只在时间匹配已有增益而幅度仍偏低时考虑。 |
