# E0032 实验设计：训练集拟合的首窗偏移衰减基线（R0）

状态：设计已冻结，本地验证运行已完成。E0032 对应 [残差预测实验计划](residual_prediction_experiment_plan.md) 的 R0。运行记录为 `E0032-s42-20260923T052241Z-8d7ca92`；正式测试集确认和实验结论仍未进行。

## 1. 研究问题与假设

**问题**：在只观察被试首窗 FC 的条件下，训练集拟合的时距衰减系数能否比群体未来模板、FC1 持续和 E0031 使用的固定系数 1 偏移基线更准确地预测未来 FC？首窗个体偏移在无重叠长期区间还剩多少可泛化信号？

**假设**：固定系数 1 将短期观察到的个体偏移外推至所有未来窗口，可能过度保留该偏移。按训练集估计的共享 `alpha[t]` 可以随时距收缩偏移，使验证集长期边 MSE 下降；若长期 `alpha[t]` 接近 0 且 E0032 未优于群体模板，则单个首窗对长期 FC 的可检出增益有限。后一结果不能证明所有残差不可预测，也不能证明 SC 或更多 FC 历史无用。

**唯一主要变化**：将 E0031 的零学习残差解析基线中的固定首窗偏移系数 `1` 换成训练集拟合的逐时距共享标量 `alpha[t]`。E0032 不训练神经网络，不使用 SC，也不改变数据或验证划分。其直接对照是 E0031 的 `context_residual_zero`，同时必须报告群体模板与 FC1 持续。

## 2. 固定数据与预测定义

- 使用 `dataset_lr_v1`、`split_lr_v1`，被试级 train/val/test 为 `738/158/159`；AAL90、83 TR 窗长、5 TR 步长、Fisher-z 上三角 4005 条边、1 个首窗作为条件、其后 223 个窗口作为目标。
- 对训练被试 `s`，记首窗为 `x[s,e]`，第 `t` 个未来窗口为 `y[s,t,e]`，`t=0,...,222`。令 `g0[e]` 为训练集首窗均值，`g[t,e]` 为同一训练集未来窗口均值，`delta[s,e]=x[s,e]-g0[e]`。
- 每个时距用**同一个跨训练被试、跨边共享的标量**：

  `alpha_raw[t] = sum_train,s,e(delta[s,e] * (y[s,t,e]-g[t,e])) / (sum_train,s,e(delta[s,e]^2) + 1e-12)`，

  `alpha[t] = clip(alpha_raw[t], 0, 1)`，

  `B[s,t,e] = g[t,e] + alpha[t] * delta[s,e]`。

- 所有求和及拟合以 float64 执行；保存 `alpha_raw`、裁剪后的 `alpha`、训练被试数、数据/划分哈希及训练模板哈希。预测和评价可使用 float32，但各方法须使用相同精度口径。
- 本实验预先固定为**不平滑、不调参**的逐时距估计。若训练曲线噪声需要平滑，应另立配置或实验；不得看验证集后修改 E0032 的 `alpha`。
- 只用训练折拟合 `g0`、`g`、`alpha`。验证被试的 `x` 仅用于生成自身预测；验证 `y` 仅用于评价。测试集不参与拟合、调参或本轮结论。

## 3. 对照与评价

使用同一批验证被试、同一真实目标和同一训练模板计算：

| 方法 | 预测 | 作用 |
| --- | --- | --- |
| 群体模板 | `g[t,e]` | `alpha=0`；检验首窗信息是否带来增益 |
| FC1 持续 | `x[s,e]` | 完全不随时距变化的简单基线 |
| E0031 零残差 | `g[t,e]+delta[s,e]` | `alpha=1`；E0032 的直接结构对照 |
| E0032 / R0 | `B[s,t,e]` | 训练集拟合的时距衰减基线 |

**主指标**：验证集无重叠长期窗口 `t=17,...,222` 的逐被试 Fisher-z 边 MSE，再对被试等权平均；越低越好。`t=17` 是首窗之后的未来标签索引，不与首窗共享原始 BOLD 样本，但并非统计独立。

**必须报告**：

1. 四种方法的全程及 `0:17`、`17:85`、`85:154`、`154:223` 四段边 MSE、MAE 和逐被试 MSE；报告每段的样本数和真实索引边界。
2. E0032 相对群体模板与 E0031 零残差的逐被试长期 MSE 差值，按被试有放回抽样 2000 次、固定 bootstrap seed 42 的均值差及双侧 95% 百分位区间；差值定义为 `MSE(E0032)-MSE(对照)`，负值表示改善。
3. `alpha_raw[t]` 与 `alpha[t]` 的逐时距曲线、裁剪到 0/1 的时距数量，以及四个区间内的均值/中位数。报告验证集各时距 MSE 曲线，以检查改善是否仅出现在与首窗重叠的早期窗口。
4. 真实残差 `r=y-B` 在训练集和验证集的总体 MSE、逐时距方差，以及稳定残差 `m=mean_t(r)` 与去时间均值动态残差 `d=r-m` 的尺度和被试间离散度。这是后续 R1 的目标审计，不从验证残差重新拟合参数。
5. 未来平均 FC 的被试检索 Top-1/Top-5/平均排名、预测跨被试离散度与真实离散度之比。上述指标只描述稳定个体信息；R0 的模板时间变化及 `alpha[t]` 趋势不能当作学到正确动态相位的证据。

训练集样本仅用于拟合与目标审计；所有性能比较和决策基于验证集。被试若有多个 run，先在被试内平均指标，再做被试级汇总与 bootstrap。

## 4. 预先固定的结论规则

- **主成功条件**：E0032 的长期 MSE 相对群体模板和 E0031 零残差均下降，且两个配对差值的 95% bootstrap 区间上界都小于 0。此时可说首窗偏移经训练集时距校准后提供了可泛化的长期 FC 水平信息，并将 E0032 冻结为后续 R1 的零残差基线。
- **部分结果**：若仅优于 E0031 零残差而未优于群体模板，结论为“固定系数 1 外推过强”；不能说首窗提供了长期增益。若仅优于群体模板而未稳定优于系数 1，则报告首窗信号存在，但时距校准的附加收益未确立。
- **无明确增益**：若相对群体模板未稳定改善，仍保留 E0032 的残差定义和完整结果供 R1 对照，但不把解析基线的长期准确性称作成功。后续是否开展 R1 应依据其独立的残差可预测性检验，不能仅由 E0032 的成败决定。
- 不用原 E0031 模型的 `objective_loss` 与 E0032 的边 MSE 直接比较。可以把 E0031 的验证预测作为描述性参照，但它不进入 E0032 的主判据。

## 5. 实施与产物边界

现有 `context_residual_zero` 固定使用 `alpha=1`，解析实验运行器仅识别 `group_mean` 与 `fc1_persistence`。因此运行 E0032 前需增加独立的 `fc1_decay_template` 解析基线，复用训练折统计和受管实验的数据/划分校验，并让配置明确记录 `alpha` 拟合与评价口径。不得把 E0032 配置伪装成现有解析模型直接运行。

建议产物：冻结配置及登记行；训练折 `alpha`/模板工件和来源哈希；验证集 `evaluation_val.json`（含四方法聚合与逐被试结果、分段指标及配对区间）；残差目标审计与 `alpha` 曲线。

## 6. 本地验证运行记录

本地 seed 42 运行使用 `dataset_lr_v1`、`split_lr_v1` 和训练折 738 个样本。验证集 158 个被试的长期边 MSE 为：E0032 `0.185801`，群体模板 `0.192718`，E0031 固定 `alpha=1` 零残差 `0.295914`。E0032 相对群体模板的被试 bootstrap 95% 区间为 `[-0.008957, -0.005042]`，相对 E0031 零残差为 `[-0.118216, -0.102421]`；负值表示 E0032 损失更低。
