# 实验可视化合约

本合约适用于此后为受管理实验生成的所有可视化。

## 目录与命名

每个实验的可视化目录固定为：

```text
outputs/E####/
├── runs/
│   └── <run_id>/
└── visual/
```

`visual/` 必须与该实验的 `runs/` 目录同级；不得把跨实验或实验级图放入某个不可变的 `runs/<run_id>/` 目录。涉及特定 run 的图和脚本以 `<run_id>_` 作为文件名前缀；涉及多个 run 的比较图以参与实验 ID 或清晰的比较名称作为前缀。

## 交付格式

- 每张图都必须由同一目录下的、可重复运行的 `.py` 脚本生成。
- 必须提交生成的静态图片，默认使用 PNG；适合印刷或需要无损缩放时可额外提交 PDF 或 SVG。
- 不得以 HTML、交互式网页、Notebook 输出或仅保存脚本作为可视化交付物。
- 脚本应从受管理 run 的 `config_resolved.yaml`、`metrics_*.json`、`evaluation_*.json`、动态审计结果或明确列出的预测工件读取数据；不得隐式读取后来修改的实验配置。

## 统一研究图样式

- 主动态图固定展示 4 条边：以 `np.random.default_rng(42)` 从 4005 条上三角边中无放回抽取并按索引排序。所有实验与模型对比共用此集合。
- 主动态图按“边为行、模型为列”排布；真实曲线始终为蓝色，预测曲线始终为橙色。同一条边跨模型共享 y 轴范围。
- 标题、图例和模型列标题须使用独立布局区域，并采用 Matplotlib `constrained` 布局；不得用手调 `suptitle(y=...)`、浮动顶部图例或 `tight_layout` 争抢绘图区。
- 动态校准柱图使用固定 `width=0.42`，分类轴按类别中心 `[-0.5, N-0.5]` 留白；单模型和双模型图不允许柱体铺满绘图区。
- 每个已完成实验的验证集报告默认包含：运行概览、固定四边动态、动态校准、分段长程审计四张 PNG。实验比较图归属到提出该对照的新实验目录。

## 最低可追溯性

每个脚本文件开头应注明实验 ID、涉及的 run ID、数据 split、输入工件和生成图片名。图中应在标题、图注或文件名中标明实验 ID、run ID 与 split，避免验证集图和最终测试图混淆。

历史的 `visualization/` 目录不要求迁移；本合约只约束后续新增内容。
