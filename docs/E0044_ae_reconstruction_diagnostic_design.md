# E0044（拟议）：冻结 FC 自编码器的空间与时间重建诊断

设计日期：2026-10-20。状态：诊断代码、正式配置与合成流程测试已实现；已完成真实数据完整诊断，诊断 ID 为 `E0044-20261020T070318Z-b83fc41d`。E0044 使用独立 `ae-diagnostic` 入口，不创建训练 run，不增加 completed_runs。本方案不修改 E0003 或 E0040–E0043 的工件、结果与选模规则。

## 1. 目的与可回答的问题

当前 E0040–E0043 的完整未来预测时间标准差比约 0.13–0.16，时间 Pearson 约 0.095–0.098。不能据此认定 AE 是原因：单窗编码、历史汇总、预测头、损失和未来不确定性都可能影响波动。

本实验把 GRU、未来查询和预测头全部移除，逐窗计算 `X_hat = D(E(X))`，定位在进入历史模型之前，既有 AE 的编码—解码映射是否已明显削弱 FC 的时间变化。它回答三个问题：

1. 连接数值和每窗连接结构是否被准确重建？
2. 对同一条连接边，时间波动的幅度、形状与相邻变化是否被保留？
3. 这种动态保真度相对于简单稳定重建、同压缩维度线性重建如何？

这是同期重建诊断：每一窗真实 FC 都被送入编码器。它不预测未来，不提供未来预测性能，也不能证明被重建的波动全部是神经信号。AE 编码器与解码器的共同误差不能单凭本实验拆开；差的重建不等于 latent 完全没有动态信息。

## 3. 时间区间与推理

对每名被试完整 LR run，读取 `X[0:224, 0:4005]`，以可控 batch 逐窗编码和解码，恢复同形状 `X_hat`。不需要将 224 窗一次放进显存。只执行一次全 run 重建，再切片评价：

| 区间 | 零基索引 | 用途 |
| --- | --- | --- |
| 完整扫描，主诊断 | `[0:224]` | 用较长时间序列评价 AE 本身的动态保真度 |
| 预测任务目标对齐区间，必报 | `[20:224]` | 对齐 E0040–E0043 的完整未来 204 窗 |
| K=20 实际历史 | `[0:20]` | 检查真正进入历史 GRU 的信息 |
| K=10 / K=5 历史，探索性 | `[10:20]` / `[15:20]` | 判断局部历史的动态保真度；短段相关不稳定，单独标记 |
| K=1 历史 | `[19:20]` | 只报告逐窗误差和空间相关，不计算时间相关、差分或时间标准差比 |

主结论基于完整扫描，并要求与 204 窗区间一起解释。不以长期无重叠子段替代完整区间。窗口高度重叠，不能当成独立样本计算显著性。未来区间送入 AE 仅用于同期重建；不得将这些编码结果作为历史预测输入。

所有方法评价同一验证被试、相同时间窗与边，且输出维度相同。

| 方法 | 构造 | 目的与限制 |
| --- | --- | --- |

| 训练集静态均值 | 训练被试完整 run 的逐边时间均值，再对被试等权平均，验证期每窗重复 | 检查只输出稳定连接结构就能取得多少空间分数；动态为零 |
| 训练集时间模板 | 训练被试在每个扫描窗位置的 FC 等权平均 | 检查是否只恢复了群体共享的时间变化 |
| 被试自身区间时间均值，oracle 诊断参照 | 对待评区间求 `bar X` 并重复 | 演示保留全部区间均值、丢弃全部动态时的表现；使用真实评价区间，不能部署、不能用作预测基线 |

实现固定使用 randomized PCA，`n_oversamples=20`、`iterated_power=4`、`power_iteration_normalizer=QR`，float32 临时磁盘映射训练矩阵，拟合后删除临时矩阵。当前协议要求每名训练/验证被试恰有一个完整 LR run；不完整时直接报错，不静默重采样。PCA 使用全部 224 窗，与既有 AE 训练代码每 run 固定抽取 32 窗的覆盖不同；比较用于诊断当前工件，不把差异全部归因于线性/非线性结构。

## 5. 指标：分别评价数值、形状和幅度

令某一评价区间中 `X[t,e]` 为真实 FC、`Y[t,e]` 为重建 FC，二者形状 `[T,4005]`。以下按 run 计算。

### 5.1 整体重建：是否恢复连接结构

- Fisher-z 逐边 MSE、MAE。
- 空间 Pearson：每个 t 沿 4005 条边计算，再对窗口平均。
- 时间均值偏差：`mean_e((mean_t(Y)-mean_t(X))**2)`。
- Fisher-z 为主报告；`tanh` 后原始 r 空间的误差和标准差比为补充，避免混淆两种数值空间。

空间 Pearson 高只说明连接的相对强弱相似，不能替代数值误差或时间指标。

### 5.2 主指标：去均值动态归一化 MSE

分别去掉真实和重建序列各自的逐边时间均值：

`Xc = X - mean_t(X)`，`Yc = Y - mean_t(Y)`。

主指标：

`dynamic_nmse = sum((Yc-Xc)**2) / sum(Xc**2)`。

这是每个 run 内先累计时间与边的能量，再取比值；不是对每条边的比值求平均。

- 0：动态完全重建。
- 1：与完全去掉动态的静态重建同等动态误差。
- >1：动态误差比输出常量还大。

它同时惩罚动态形状和幅度错误，但会更重视真实动态能量较大的边；必须与逐边指标一起报告。分母为零时记 null，不填零。

还报告去均值动态 MSE，并核对恒等分解：

`total_mse = mean_bias_mse + centered_dynamic_mse`。

它帮助判断整体误差来自稳定水平偏差还是动态误差；不将 `1-dynamic_nmse` 解释为普适的“信息保留百分比”。

### 5.3 时间形状：起伏是否对齐

逐边 `corr_t(Y[:,e], X[:,e])`，有效边等权平均，再按被试聚合。分别报告原时间序列和一阶差分的时间 Pearson。去时间均值不会改变 Pearson，因此不把去均值 Pearson 包装为一个新指标。

差分采用相邻窗 `diff(X, axis=0)`，不跨被试/run/切片边界。相关高、幅度低表示形状保留而振幅收缩；相关低、幅度接近 1 表示存在波动但时间方向不正确。

### 5.4 幅度：曲线是否变平

- 逐边时间标准差比 `std_t(Y)/std_t(X)`，报告均值、中位数、分位数。
- 整体动态能量比的平方根 `sqrt(sum(Yc**2)/sum(Xc**2))`，作为对小方差边不那么敏感的补充。
- 一阶差分归一化 MSE：`sum((diff(Y)-diff(X))**2)/sum(diff(X)**2)`。

标准差比接近 1 不等于重建正确，随机波动也可能满足。不要以放大输出、验证集调尺度或添加噪声“修复”本诊断结果。

标准差比的中位数、5%/25%/75%/95% 分位数先在每个 run 的有效边上计算，再按同样的被试等权规则聚合；不是将全部被试的边合并后计算分位数。

### 5.5 近常数边规则

沿用新历史实验 Fisher-z 时间标准差阈值 `1e-6`，使用 float64 计算相关和中心化统计。

- 真实与重建标准差均超过阈值，时间 Pearson 才有效。
- 标准差比在真实标准差超过阈值的边上计算，预测为常数时允许比值为 0。
- 必报真实有效边比例、相关有效边比例、重建近常数边比例。
- 对比 AE 与 PCA 的时间相关时，在两者共同有效边上另给配对比较，同时保留各自覆盖率。
- 静态基线时间相关为 null，不能用 0 替代。

## 7. 判读与下一步

| 观察 | 支持的解释 | 下一步 |
| --- | --- | --- |
| 空间 r 高，但动态 NMSE 接近或超过 1、时间 r 低、标准差比小 | 既有 AE 映射保留稳定结构，动态重建不足 | 优先尝试差分/动态重建目标、部分解冻编码器；加 latent 探针区分编码器和解码器 |
| 时间 r 高、标准差比明显小 | 动态形状有保留，幅度收缩 | 检查 AE 解码器与幅度校准；不能直接断言编码信息已丢失 |
| 标准差比接近 1，但时间/差分 r 低 | 有波动，但形状或变化方向错误 | 不以幅度指标单独判成功，优先检查动态表示 |
| AE 动态指标接近恒等参照、明显优于静态参照 | AE 重建环节不足以解释预测变平 | 优先查 GRU 最后状态汇总、历史是否被使用、预测目标与损失 |
| PCA 动态明显优于 AE | 同为 256 维，当前非线性 AE 的训练/映射可能有问题 | 将 PCA 编码作为后续预测的线性对照；不直接宣称所有 256 维表示都足够 |
| AE 与 PCA 均差 | 两种现有压缩映射都不足 | 后续比较更大维度、差分分支及无 AE 投影对照；不能仅凭此证明维度是唯一原因 |
| 完整扫描好，前 20 窗差 | 可能是局部幅度小、时间段差异或短段估计不稳 | 看绝对动态误差/真实动态能量，补预定等长片段分布再定位 |

不预设缺乏领域依据的“r>0.8 才合格”等阈值。结合被试区间、AE−PCA 配对差异、恒等/静态参照和下游用途判断。一次同期重建诊断不能给出未来可预测性的上限。
