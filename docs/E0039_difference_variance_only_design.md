# E0039：只用差分与方差训练 E0036 架构

## 实验问题

E0038 将差分与方差加入逐点 MSE 后，动态标准差比从 E0036 的 0.00166 升至 0.00229，但真实动态相关仍接近零。E0039 检查一个更直接的问题：完全去掉训练中的逐点边 MSE，只让相邻窗变化与时间方差约束残差，能否提高未来动态的时间对齐？

沿用 E0036 的 FC1-only 直接残差 Transformer、冻结 E0003 编码器、冻结 E0032 解析基线与 alpha、数据划分、seed 42、优化器、学习率日程和 150 epoch 预算。SC 在编码后置零。相对 E0036，只有训练目标改变；相对 E0038，同时去掉逐点项并把差分系数从 0.25 提到 1.0，因此 E0039 对 E0038 的差异不能归因于单独一项。

## 损失定义

令 `B` 为冻结 E0032 基线，`r = y − B` 为真实残差，`r_hat` 为模型输出。训练目标固定为：

`L = 1.0 × MSE(Δr_hat, Δr) + 1.0 × MSE(Var_t(r_hat), Var_t(r))`。

`Δ` 是 223 个未来窗的一阶相邻差分，`Var_t` 是每名被试、每条边在该序列上的有偏时间方差。两项均使用代码现有的原始 MSE 定义；**1:1 是系数比，不保证梯度贡献相等**。逐点边 MSE、静态、对比及其他损失系数均为零，不做损失归一、权重搜索或额外输出校正。

此目标有精确的平移不变性：任意逐被试、逐边常数 `c` 满足 `L(r_hat + c, r) = L(r_hat, r)`。因此训练无法识别残差的时间均值；即使预测变化完全对齐，完整 FC 数值也可能因常数偏移而变差。这是实验要量化的固有限制，不在本轮偷偷加入均值锚定，否则便不再是纯差分加方差目标。

## 运行与评价协议

按固定 seed 42 完整训练 150 epoch，不早停。沿用 E0036 的验证集无重叠段 `t=17:223` 长期边 MSE 选 checkpoint；选模指标含逐点 MSE，但训练损失不含它。这样保持 checkpoint 比较口径一致，也需要明确：验证集选模可能偏向偶然具有较小常数偏移的轮次。验证集只用于预定选模和分析，绝不据此改 E0039 权重；不查看测试集。

对同一批被试与 E0036、E0038 做配对比较，报告长期边 MSE 及被试级 bootstrap 95% 区间、原始与去训练折群体模板的逐边时间 Pearson、动态残差时间 Pearson、相邻窗差分 Pearson、动态标准差比和分时距 MSE。另计算每名被试每条边 `mean_t(r_hat − r)` 的平均绝对值及分布，直接揭示常数偏移；同时可报告**仅用于诊断**的时间去均值后 MSE，但不得把它当完整 FC 预测精度。

若动态相关仍接近零，或只有振幅增加而差分相关未改善，判为未获得可信动态收益。若相关改善但完整长期 MSE 因均值漂移变差，报告为有代价的动态改善，不能称完整预测更好。若 seed 42 显示明确收益，再单独登记多 seed 复验；这一轮不从验证结果重新调系数。
