# E0003 AE 与 E0044 PCA：训练数据范围及泄露审计

日期：2026-10-26。审计只读历史源码和已归档证据，没有加载私人FC、模型权重或重新训练。可复现脚本：`scripts/audit_ae_pca_training_scope.py`；机器可读结果：`reports/experiment_notes/E0003_E0044_training_scope_audit_20261026.json`。

## 1. 结论与认证范围

**历史代码没有发现验证/测试FC进入AE梯度更新的路径；归档证据支持E0044的PCA只使用训练集LR拟合。不能据此无条件保证历史运行完全没有任何形式的数据泄露。** 本机没有原始split文件、私人数据/实际缓存和A0003完整权重；旧AE也未记录逐run/窗口训练清单。

核查必须使用E0003当时的提交`4d4337d982b85c3f75852ca79e203b4fbf0c8dcf`，而不是把当前代码当成历史代码。

| 核查 | 结果 | 证据含义 |

| E0003冻结配置哈希 | 与metadata一致 | 可定位当时协议 |
| 原数据manifest摘要 | 与E0044引用一致 | 两次使用同一声明的数据版本 |

E0044运行时工作区为dirty；不能仅按其git commit复现。但计算源码和相关结果已逐文件归档并保存哈希，本次检查了关键文件哈希。此限制应保留。

## 2. AE与PCA实际使用的数据不同

历史AE代码为每个训练run建立32个抽样槽位，验证run为8个。每个槽位由`default_rng(seed+index)`产生窗口索引：**有放回、跨epoch固定**，不是每轮再随机抽32个新窗口。

在“旧AE缓存只有与E0044相同排序的738个LR run”这个条件下，可精确重放：

- 每轮训练槽位23,616个。
- 不重复的训练窗口22,012个；每人25–32个不重复窗口。
- PCA训练使用738×224=165,312个窗口。
- 抽样AE访问的不同窗口约为PCA的13.3%；训练100轮不会扩大这个固定集合。
- batch256时每轮93次更新，100轮9,300次更新；全量组每轮646次更新。

这些旧AE窗口数量是**条件重建**：原训练没有保存实际缓存run清单，不能把它们当作已经核实的旧运行计数。

## 3. 另一个重要混杂：历史AE并非MSE训练

在原提交中，`AutoencoderLoss.edge`实际调用`F.smooth_l1_loss`，默认beta=1；E0003配置的注释与之相符。当前实现后来改成MSE。

因此，直接比较“旧SmoothL1抽样AE”与“新MSE全量AE”，会同时改变损失和数据覆盖。旧训练记录的`validation_loss≈0.0241`不能直接与E0044的`MSE≈0.0483`比较；两个量的定义不同。

用户已明确要求**新实验全部使用MSE，不使用SmoothL1**。据此设计E0048与E0049：分别重新训练抽样MSE对照和全量MSE主模型。历史A0003只作为背景参照，不事后改写损失标签。

## 4. 代码路径层面的泄露检查

历史AE：`DFCSequenceDataset(...,'train',...)`先从split得到允许的训练被试，再筛选缓存run；只有训练loader参与`loss.backward()`与`optimizer.step()`。验证使用独立val loader、`model.eval()`和`torch.no_grad()`，用于选checkpoint。验证选模是既定开发用途，不等于验证梯度训练。未发现测试loader参与这一路径。

历史训练统计也先筛选训练被试再拟合SC/FC统计；AE的输入直接来自自身FC窗口，不把整个split混成一条训练轨迹。缓存可以预计算所有split，但预计算存在测试缓存本身不等于拟合使用测试样本。

E0044：`_fit_references`只接收`samples['train']`，构建165,312×4,005的训练矩阵，PCA只调用该矩阵的`fit`。验证样本只用于`transform/inverse_transform`及诊断指标；没有用验证/测试重新拟合均值或主成分。配置中的oracle均值只作诊断参照，不参与PCA/AE训练。

## 5. 仍不能认证的内容

1. **旧LR白名单缺失。** 原`iter_cached_samples`枚举缓存内全部run，不按`paths.timeseries`过滤。如果缓存残留RL，同一训练被试的RL也可能进入旧训练；这不是验证被试泄露，但会破坏LR-only比较。历史运行没有逐run清单，当前不能排除此情况。
2. 本机无法重读原始FC/权重，不能做原机器运行级最终认证；归档摘要检查不能代替实物复核。
3. 缺少家庭ID，不能认证家系隔离；不能将被试ID隔离表述为家系隔离。
4. 上游BOLD处理是否使用跨被试统计、局部/近似重复、历史其他实验对test的探索不由本次源码审计证明。不能宣称测试集从未被查看，或已证明在线前瞻因果性。

## 6. 新实验的补强

E0048/E0049逐个从已验证split的train/val名单显式读取LR；每个run的FC值与时间轴哈希必须与E0044原PCA审计完全一致，否则启动训练前失败。所有训练窗口都保存源清单摘要，并额外保存真正参与梯度的索引摘要、槽位数和不重复窗口数。只对train更新参数，val只选模，不读取test FC。新旧工件与原结果均不覆盖。
