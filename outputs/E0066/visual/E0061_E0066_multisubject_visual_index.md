# E0061–E0066 多被试图与α曲线

验证集固定四被试 S1–S4、六条边，沿用用户指定 E0037 参考图的选择；第五列为训练集组均值。

FC图同一条边跨所有实验共用y轴范围。α曲线不平滑、不截断；六面板共用尺度；另提供Δα和第18–60窗放大图。

α为冻结组件，同被试下E0061/E0064、E0062/E0065、E0063/E0066的α逐点相同，已验证。
