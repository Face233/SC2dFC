# 时间信息塌缩与个体特异性缺失：项目诊断与方法调研

日期：2026-09-07。检查代码提交：`a72a103d84feb6f5f36b433792adde01f62d7894`。

**核心结论：目前存在两种不同的退化。** 带边重建的模型保留部分个体连接特征，但时间变化接近常量；去掉边重建后，模型能够产生波动，却主要生成跨被试共享的时间轨迹。后者不是已经解决时间塌缩，而是从“几乎不动”变成“大家一起动”。优先处理损失的不可辨识性、个体条件利用和评价口径，再判断是否需要改变预测任务或引入概率模型。

本次检查包括模型、条件编码、滑窗数据、损失、训练选模、评估、E0004—E0024 的可用验证报告和相关原始论文；另对三个现有 checkpoint 做了 16 名验证被试的前向诊断。没有训练新模型，也没有修改原有代码、配置、实验注册表或历史结果。新诊断不读取测试集。

## 1. 项目实际上在预测什么

当前主任务是 `SC + FC[0] → FC[1:224]`：AAL90、4005 条边、83 TR 矩形窗、5 TR 步长、TR=0.72 秒。首窗覆盖 59.76 秒，后续窗口起点每次移动 3.6 秒；模型一次生成 223 个未来 FC 窗口，最后一窗终点距首窗终点约 802.8 秒。

SC 和首窗 FC 被压缩为一个 256 维全局条件。GRU/Transformer 读取“共享的可学习时间 query + 个体条件”，再经冻结的 E0003 decoder 输出 Fisher-z 边。代码**有时间 query，并非完全没有时间编码**；问题是网络可以主要依靠 query 生成公共轨迹，而弱化个体条件。Transformer 当前没有对独立 SC/FC token 做 cross-attention。

E0018、E0022、E0023、E0024 实际使用 `difference + variance`，`edge=0`。README 中包含八项损失和残差相关选模的部分描述，不代表这些运行的实际设置；当前 `CompositeLoss` 还限制最多三个非零损失项。应以 run 的 `config_resolved.yaml`、checkpoint 和 `train.log` 为准。

## 2. 已确认的实验现象

### 2.1 全验证集：幅度恢复不等于时间预测恢复

下表来自 158 名验证被试。动态指标采用现有审计的 `nonoverlap` 区间，先计算每名被试的逐边中位数，再取被试中位数；MSE 和检索指标来自同一 run 的验证评估。MSE 是全预测段 Fisher-z 边误差，不能与动态指标误认为同一聚合方式。

| 实验 | 主要设置 | 时间标准差比 | 差分标准差比 | 差分时间相关 | 个体检索 Top-1 | 边 MSE |
|---|---|---:|---:|---:|---:|---:|
| E0013 | GRU，边 MSE＋差分 | 0.0766 | 0.0033 | 0.0028 | 3.16% | 0.1844 |
| E0018 | GRU，仅差分＋方差 | 1.0161 | 0.0880 | -0.0002 | 0.63% | 2.4586 |
| E0022 | Transformer，仅差分＋方差 | 1.0099 | 0.2133 | 0.0011 | 0.63% | 2.1141 |
| E0023 | Transformer，延长至 100 epoch | 0.0094 | 0.0234 | -0.0018 | 0.63% | 2.0012 |
| E0024 | Transformer，warm-up＋余弦退火 | 0.9613 | 0.3155 | 0.0029 | 0.63% | 2.2975 |

158 人单个正确匹配的随机期望为 `1/158=0.6329%`，Top-5 为 `5/158=3.1646%`，平均排名为 79.5。E0024 三项恰好都是这些值；单凭这一点不能证明所有输出相同，但它与下面的直接诊断一致。E0013 仍保留一些个体信息，不能把全部历史模型都称为彻底的个体塌缩。

E0024 的长期低频功率比为 0.8666，但中频功率比仅 0.00327；其幅度接近真实，主要不代表中频细节恢复。E0018 的 FCD Pearson 达 0.5579，但差分时间相关接近零、检索近随机，说明单看 FCD 相关也可能误判。共享的滞后结构和趋势可以产生一定 FCD 相似性。

既有 E0014/E0015 已测试 warmup K=1/K=5，分别仍只有约 0.00278/0.00280 的差分标准差比，未显现动态幅度恢复。但两组标签起点不同，这些现有汇总不构成共同绝对时间区间上的正式对比。K=5 的五个重叠窗口仅覆盖 74.16 秒，比 K=1 多 14.4 秒；不能据此判定更长历史、BOLD 历史或不同历史编码都无效。

### 2.2 新增 checkpoint 诊断：公共动态轨迹得到直接支持

固定随机种子 42，从验证集抽取相同的 16 名被试，对 E0013、E0018、E0024 的最佳 checkpoint 前向计算。去掉前 17 个预测窗口，与既有长期审计一致。

| 诊断 | E0013 | E0018 | E0024 |
|---|---:|---:|---:|
| 预测跨被试离散程度 / 真实跨被试离散程度 | 0.2170 | 0.0916 | 0.0364 |
| 不同被试预测动态相似性 | 0.8215 | 0.9942 | 0.9998 |
| 不同被试真实动态相似性 | 0.0033 | 0.0033 | 0.0033 |
| 交换 SC 导致的输出变化 / 真实跨被试离散程度 | 0.0070 | 0.0104 | 0.0043 |
| 交换 FC1 导致的输出变化 / 真实跨被试离散程度 | 0.3196 | 0.1294 | 0.0544 |

定义：离散程度是固定时间、固定边上减去被试均值后的总体 RMS；动态相似性是先对每名被试每条边沿时间去均值，再展平时间×边，计算所有被试对的余弦相似性并取中位数。由于已时间去均值，该相似性不包含固定的边均值。交换条件使用无自配对的循环置换，SC 的矩阵和边向量同步交换。

因此，E0024 的问题不只是整体 FC 拓扑相似：**去掉各条边的静态均值后，动态部分仍几乎完全一致。** 对 SC 交换的响应非常小，也提示当前模型很少利用个体 SC。条件交换只是已训练模型的敏感性诊断，不能替代重新训练的 SC 消融，也不能证明 SC 在任务中没有信息。

同一批真实未来 FC 经 E0003 encoder→decoder 重建后，时间标准差比为 0.8188，差分标准差比为 0.8021，差分时间相关为 0.7991。自编码器确实压缩了一部分动态，但其重建表现远好于预测模型。因此“冻结 decoder 必然只能输出平线”不成立。该实验使用真实未来，仅用于表示能力诊断，不能作为可部署预测性能或严格的性能上界；它也尚未排除预测 latent 偏离自编码器训练分布的问题。

16 人诊断属于机制检查，未做全验证集条件交换或置信区间；不能把小样本数值当作最终总体估计。

### 2.3 评价记录问题（已于同日修复）

训练期间 `training.py` 使用配置中的完整 `CompositeLoss` 选 best checkpoint；但 `evaluation.py:77` 总是报告：

`objective_loss = edge_loss + difference_weight * difference_loss`

它没有应用 edge 权重，也没有包括 variance、long_horizon_variance 等其他成分。随后 `managed_cli.py:231` 用评估结果覆盖 `metrics_best.json`，使同一个字段在训练和评估阶段含义变化，并丢失原先的 best_epoch 等信息。

| 实验 | checkpoint / 训练日志中的真实最佳目标 | 评估后同名 objective_loss |
|---|---:|---:|
| E0018 | 0.01274560 | 2.46818870 |
| E0024 | 0.01481201 | 2.30797902 |

这两个实验的动态目标同为差分 MSE＋方差 MSE。若只看汇总表中被覆盖的数字，会得出与真实训练目标排序相反的结论。**此问题污染报告与跨实验比较，但当前代码中的训练选模本身使用正确目标；不能把预测塌缩归因于这一记录问题。**

现已将 `metrics_best.json` 固定为验证集选模记录，通用评价继续保存在 `evaluation_<split>.json`；固定边＋差分指标改名为 `edge_difference_score`。历史值已从 checkpoint 恢复，旧文件均有本地备份。具体变更和唯一未能恢复的 E0013 见同目录的《指标口径修复结果》。

## 3. 为什么出现这两种塌缩

### 3.1 仅差分＋方差无法识别个体连接的基准水平

对任意随被试和边变化、但不随时间变化的偏置 `b[s,e]`：

`Δ(p+b)=Δp`，且 `Var_t(p+b)=Var_t(p)`。

所以 `L_diff + L_var` 对所有这类偏置完全不敏感。模型输出处在何种平均连接水平、是否具有本人平均 FC，不由这两项损失确定。冻结 decoder 带来隐式限制，但不能替代对正确个体均值的监督。这是从当前损失公式可以直接确认的不可辨识性。

另一个缺口是 difference 只比较预测序列内部相邻窗，没有包含“最后 warmup FC → 第一个预测 FC”的边界差分；仅动态训练时连初始连接水平也没有直接锚定。

### 3.2 差分 MSE 与全程方差可能共同偏好慢速公共轨迹

如果给定当前条件后，个体未来差分的条件期望接近零，差分 MSE 会倾向压小预测差分。全程方差又要求序列有足够幅度。一个满足两者折中的解是：用缓慢漂移或低频起伏产生方差，避免快速变化带来的差分惩罚。

这不是简单的“差分损失权重不够大”：加大它，在相位无法预测时可能进一步压平曲线。方差只决定幅度，不决定频谱、顺序或个体身份。共享时间 query 为公共慢轨迹提供了方便的表示。本项目的 E0018/E0024 诊断与这一机制吻合，但优化因果关系仍需单因素实验验证。

此外，对于逐边方差 MSE，预测严格为时间常量时，方差对预测的导数为零；因此“加入方差项必然能把完全塌缩的输出推开”也不成立。

### 3.3 FC1 对未来动态状态的可观测性有限

窗口相关矩阵聚合了约一分钟 BOLD。它丢失窗内时间排列信息，例如所有 ROI 同步倒序不会改变该窗口的相关矩阵，却会改变窗口末端的瞬时历史。因此 FC1 不能一般性地视为完整动力学状态。

对不确定未来使用确定性平方误差回归时，最优点预测是条件均值。若不同可能轨迹相位不一致，其平均可以很平滑。**这解释一种可能的统计限制，并不证明当前数据的未来完全不可预测。** 需要用短期预测、更多历史和适当零模型估计实际可预测时距。

相邻滑窗共享 78/83≈94% 的 BOLD 样本，短期效果包含窗口重叠带来的信息。即使不与首窗共享样本，也仍可能有 BOLD 自相关；“nonoverlap”不等于统计独立。

## 4. 文献中哪些方法值得借鉴

以下是针对当前机制的定向文献调研，不是穷尽式系统综述。静态 SC→FC、任务激活预测和通用时间序列论文，均不能被当成已验证本项目设定的直接证据。

| 原始资料 | 核心启发 | 在本项目中的用途与边界 |
|---|---|---|
| [Hindriks et al., 2016，滑窗能否揭示 dFC](https://pmc.ncbi.nlm.nih.gov/articles/PMC4758830/) | 滑窗波动需要适当的统计零模型；有限时长下检验功效可能很低 | 在原始 BOLD 层生成保留静态协方差和时间结构的平稳代理数据，再走同一滑窗流程，估计多少波动可由采样产生。不能由该论文直接断言本项目没有真实动态 |
| [Can structure predict function at individual level?, 2024](https://pubmed.ncbi.nlm.nih.gov/38656375/) | SC→FC 高空间相关可能主要来自群体共有结构；需要强基线 | 加入训练均值、FC1 持续、均值收缩和打乱 SC 对照，单独检验个体增益 |
| [Zalesky et al., 2024，个体 SC→FC 的证据与评价](https://pubmed.ncbi.nlm.nih.gov/39735518/) | 与正确零模型比较后，个体效应可以显著但幅度有限；自身匹配应优于他人匹配 | 报告匹配矩阵的对角/非对角差、置换检验和检索，避免只报告 raw Pearson；这与前一篇形成必要的不同视角 |
| [Finn et al., 2015，connectome fingerprinting](https://pmc.ncbi.nlm.nih.gov/articles/PMC5008686/)；[Amico & Goñi, 2018，identifiability](https://arxiv.org/abs/1707.02365) | 个体连接指纹及自身/他人可辨识性可独立量化 | 评价本人预测与本人真实未来的匹配优势；静态指纹成功不能代表动态相位预测成功 |
| [Ngo et al., MICCAI 2020，BrainSurfCNN](https://arxiv.org/abs/2008.02961) | 重建与对比目标联合约束个体化输出 | 借鉴“本人比他人更匹配”的目标；原任务是 FC→任务激活，迁移到 dFC 需重新验证 |
| [FreDF，ICLR 2025](https://arxiv.org/abs/2402.02399) | 频域学习是处理时间依赖的有效研究方向 | 区分相位敏感的复数频谱目标与仅匹配功率的目标。建议针对本项目测试去均值、多尺度 log-power 校准；不是声称 FreDF 原式就是无相位功率损失 |
| [Vidaurre et al., PNAS 2017，脑网络动态的时间层级](https://pmc.ncbi.nlm.nih.gov/articles/PMC5715736/) | HMM 状态转移及占据比例可体现个体差异 | 若逐窗相位难预测，可预测状态占据、转移和停留分布；原研究直接建模 fMRI，其方法不能等同于当前 KMeans 状态评价 |
| [Rasul et al., ICML 2021，TimeGrad](https://proceedings.mlr.press/v139/rasul21a.html) | 用条件分布采样预测多变量未来 | 在潜空间做随机状态模型或条件扩散，分别评价样本动态和分布校准。通用序列结果不保证 HCP dFC 有效 |
| [Benkarim et al., 2022，Riemannian SC→FC](https://pubmed.ncbi.nlm.nih.gov/35636736/) | 将连接矩阵几何与结构传播纳入映射 | 可借鉴 PSD/相关矩阵参数化；不是时间塌缩的首要解决方法 |
| [Chen et al., ICML 2018，GradNorm](https://proceedings.mlr.press/v80/chen18a.html) | 不同损失的梯度规模比损失数值本身更能反映训练影响 | 先记录各损失对共享 latent/参数的梯度范数和夹角，再决定权重；不要仅凭损失大小自动追求数值相等 |

补充：若目标允许有限的事件时间偏移，可以考察 [DILATE，NeurIPS 2019](https://papers.nips.cc/paper_files/paper/2019/hash/466accbac9a66b805ba50e42ad715740-Abstract.html)。它适合研究形状和时间扭曲，但若任务要求精确预测 FC 时刻，不能靠对齐后分数替代原始时间轴评估，因此优先级较低。

## 5. 推荐的落地路线

### 第一阶段：修复评价，建立能识别公共轨迹的诊断

1. 分离训练选模目标和通用评估指标，恢复 E0018—E0024 等真实训练目标；历史 Huber/MSE、不同权重和预测区间分别标注。
2. 扩展本次 16 人检查到完整验证集，报告个体离散程度、时间去均值后的跨被试动态相似性、SC/FC 条件交换敏感性及被试级置信区间。原始预测相似性不能替代时间去均值结果。
3. 在现有 retrieval 外增加 `I_self-I_others` 和打乱配对的零分布。分别对时间均值 FC 与动态特征（谱、差分统计、状态比例）评价，区别静态个体性与动态个体性。
4. 在验证集短、中、长期分别与 FC1 持续、训练均值比较。补充 `g + α(h)(FC_last-g)` 收缩基线；α 只在训练/验证拟合。另做训练集 PCA＋Ridge/线性潜空间动力学基线，不用测试结果调参。

这些检查比立即换更大的 Transformer 更能判断问题在哪里。已有源码支持部分 SC 消融、差分/方差审计和检索，不必全部重写。

### 第二阶段：先恢复可辨识性，再分解个体稳定成分与动态

**最小机制实验：** 相对 E0018，固定其余设置，仅新增 `static` MSE，保留 difference、variance，共三项。它直接监督预测未来的时间均值，检验“缺少均值锚点”是否导致大幅边误差和个体检索退化。static 权重应按训练梯度诊断选择，在验证集预先固定小范围搜索；不要声称某个权重已有依据。

随后再独立测试边界锚定、边重建恢复或个体残差目标，每次只改一项。均值约束恢复身份不保证恢复动态，因此必须同时看时间去均值后的诊断。

**更明确的模型分解，属于待验证设计：**

`预测 FC[s,t] = 训练群体静态模板 + 预测个体稳定残差[s] + 预测动态[s,t]`

动态输出在预测时段上去时间均值，避免静态头和动态头互相搬运常量。稳定残差头由 SC 和历史 FC 预测，训练标签可以使用真实未来的均值，但推理输入绝不能使用它。动态分支读取有顺序的历史状态。可先冻结训练好的稳定头，再单独研究动态，最后再做联合优化对照。

身份目标应在去训练群体模板的表示上比较本人和他人；当前 `contrastive_loss` 使用未去模板的长期均值，batch=4 只有三个负例，且最新动态实验未启用它。若测试对比学习，可用较大的真实对比批次或妥善处理的队列；普通梯度累积不会自动增加每次 InfoNCE 的负例。不要使用不能泛化到新被试的自由 subject-ID embedding。

### 第三阶段：增加有效历史，测试可预测时距

优先比较三类输入：当前 FC1；覆盖更长实际时长的 FC 历史；初始 BOLD 历史或其训练集拟合的低维状态。增加 K 时应报告覆盖秒数，而不只报告窗口个数。历史编码可保留时间 token，并让未来 query 对历史/SC token 做 cross-attention，或逐层条件调制；这些是候选机制，不是对“换注意力即可解决”的承诺。

先做 1/5/10/20 步等多个预测时距，按最后观测窗口的绝对终点对齐，严格区分重叠与非重叠区间。所有新增起点样本在被试划分后生成；同一被试的多个片段不能跨 train/val/test，也不能被当成独立被试扩大统计样本量。若训练时随机截取起点、缩短长度，需要相应调整 query 和模板对齐，不能只改 DataLoader。

如果更充分的历史只改善短期，而长期相位仍不可预测，应报告有限预测时距，而不是继续要求单轨迹拟合整个未来 run。

### 第四阶段：动态幅度和频谱，或条件概率分布

若保留确定性任务，可用多尺度、去时间均值后的谱功率/自相关约束替换单一全程方差，检查是否消除“用慢漂移凑方差”。功率只反映幅度分布，不能保证本人相位，必须保留身份与时间一致性评价。简单地对全频复数 FFT 做等权平方误差，在适当归一化下由 Parseval 等价于时域平方误差，不会自动解决条件均值问题。

若研究目标允许生成“符合该个体的可能未来”，建议先做低维随机状态空间/条件高斯动力学基线，再考虑潜空间条件扩散。状态转移、噪声尺度或状态占据均应受个体条件影响；仅给确定性输出加白噪声不能恢复个体动力学。

分布模型应同时报告单样本动态统计、CRPS/energy score 等分布评分、覆盖率与区间宽度，以及匹配与打乱条件的分布差异。先固定采样数，禁止用看过真实未来后的 best-of-N 样本作为主要结论；多条轨迹先平均再检查方差，也会重新造成幅度塌缩。

矩阵合法性另设工程检查：E0024 现有报告约 50.8% 的特征值为负，提示其输出远离合法相关矩阵。可考虑由 `LLᵀ+εI` 归一化生成相关矩阵，或带 shrinkage 的 SPD 空间建模。不过 83 个时间点估计 90 ROI 的样本相关矩阵本就可能秩亏，采用严格 SPD 方法前必须处理这一点。修复几何不能代替恢复身份和时间信息。

## 6. 下一轮实验应如何决定去留

建议按以下顺序注册新的实验，保留原有 E 编号结果：

| 顺序 | 单一核心问题 | 对照与判断 |
|---|---|---|
| A | 增加 static 锚点能否恢复个体均值？ | 相对 E0018；检索和均值误差改善，同时检查公共动态是否仍存在 |
| B | 原条件是否含可用短期信息？ | 相同目标与绝对预测区间，比较历史输入；必须胜过最后 FC 持续基线 |
| C | 模型是否实际使用 SC？ | 重训练 FC-only / mean-SC / shuffled-SC，配合推理交换；若无增益，不宣称结构连接驱动了个体动态 |
| D | 方差是否由公共慢趋势提供？ | 在已有身份锚点下，用多尺度谱目标替换方差；幅度、频谱、相位、身份共同评估 |
| E | 长期应改为概率任务吗？ | 充分历史后的确定性模型与简单随机动力学对照；再决定是否值得投入扩散模型 |

不得只用“std ratio 接近 1”判定成功。至少区分三个问题：输出是否有真实量级的变化；变化是否与本人条件有关；变化是否发生在正确时间。如果第三项不成立而前两项成立，可成为个体化分布建模结果，但不能称为恢复了逐窗真实轨迹。

首轮机制探索可用一个 seed，保留通过候选后至少补至三个独立 seed，并做被试配对比较。重新训练的模型与基线采用相同数据版本和相当训练预算，提前固定选模规则。仓库已有 val/test 曲线可视化记录标为 exploratory，因此后续应如实记录既往测试集接触，不能把所有测试样本统称为从未查看过。
